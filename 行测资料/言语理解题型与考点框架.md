# 言语理解：题型与考点框架

适用用途：湖北省考行测备考中的知识梳理、专项训练和错题归类。本文按通用言语题型组织，不代表某年度湖北试卷的题量或考点分布，具体以当年大纲和真题为准。

## 一、整体框架

**题型**回答“题目让你做什么”，**考点**回答“需要依据什么判断答案”。

| 大类 | 细分题型 | 核心能力 |
| --- | --- | --- |
| 逻辑填空 | 实词填空、成语填空、混合填空 | 分析上下文，辨析词语，判断搭配 |
| 片段阅读 | 主旨概括、意图判断、细节判断、标题选择、态度观点、词句理解 | 找重点，概括主题，核对原文，合理推断 |
| 语句表达 | 语句排序、语句填空、下文推断（接语选择） | 判断先后顺序、衔接关系和话题走向 |

不同教材对部分题型的归类可能不同，例如把下文推断归入片段阅读；不影响按具体能力训练。

## 二、逻辑填空

### 1. 细分题型

| 题型 | 形式 | 训练重点 |
| --- | --- | --- |
| 实词填空 | 从实词选项中选出合适词语 | 词义侧重、搭配对象、适用范围 |
| 成语填空 | 从成语选项中选出合适表达 | 成语准确含义、使用对象、感情色彩 |
| 混合填空 | 实词和成语等组合设置 | 多空照应、选项组合验证 |

### 2. 考点一：分析语境

| 考点 | 识别线索 | 判断重点 |
| --- | --- | --- |
| 转折关系 | 虽然……但是……、然而、却 | 前后在哪个方面发生转变，不能简单找反义词 |
| 递进关系 | 不仅……更……、甚至 | 后文在哪个方面加深程度或推进含义 |
| 并列关系 | 和、同时、一方面……另一方面…… | 前后是近义、反义还是分别对应 |
| 解释关系 | 冒号、破折号、即、换言之、具体举例 | 用解释内容明确空缺词的含义 |
| 因果关系 | 因为、所以、因此、导致 | 填入后能否形成合理的原因与结果 |
| 照应关系 | 重复话题、关键词、前后举例或结论 | 空缺词是否与上下文的信息一致 |

### 3. 考点二：辨析选项

| 考点 | 需要判断的问题 |
| --- | --- |
| 词义侧重 | 几个近义词分别强调什么？ |
| 词语搭配 | 与主语、宾语或修饰对象是否搭配？ |
| 程度轻重 | 是轻微变化还是显著变化？ |
| 感情色彩 | 褒义、贬义、中性是否符合文意？ |
| 语体风格 | 书面语、口语等是否适合语境？ |
| 适用范围 | 通常用于人、事物、行为还是某种关系？ |
| 成语含义 | 是否望文生义，是否误用对象或范围？ |

### 4. 建议解题步骤

1. 阅读完整语段，明确话题和句间关系。
2. 找到空缺处的解释、照应和搭配线索，预判所需含义。
3. 比较选项的具体差别，优先排除有明确问题的词。
4. 多空题可从线索最清楚的一空切入。
5. 将整组选项代回全文，验证每一空及整体逻辑。

### 5. 错题归类

- **语境分析错误**：没看出转折、解释或照应关系。
- **词义辨析错误**：读懂句子，但分不清选项的含义。
- **搭配判断错误**：词义大致合适，但使用对象不对。
- **验证不完整**：只验证一空，没有检查其他空和全文。

## 三、片段阅读

### 1. 主旨概括题

**常见问法**：“这段文字主要说明了……”“这段文字的主旨是……”。

**核心考点**：

- 找出核心话题和作者主要观点。
- 识别总分、分总、总分总、并列等行文结构。
- 区分观点、背景、举例、原因、引用等内容的作用。
- 借助转折、因果、递进、并列、条件等关系理解重点。
- 判断选项是否覆盖全文，避免以偏概全、范围过大或偏离主题。

**常见错误**：把例子当主旨；只概括前半段；选项话题相同但观点不同。

### 2. 意图判断题

**常见问法**：“这段文字意在说明……”“作者意在强调……”。

**核心考点**：

- 先把握文段主旨，再判断作者希望表达的目的。
- 区分事实描述、问题揭示、原因分析和建议倡议。
- 判断是否有充分依据推导出对策或言外之意。
- 控制推断范围，不能脱离原文自行补充结论。

**常见错误**：看到问题就机械选择对策；选择正确但与文段目的无关的说法；过度推断。

### 3. 细节判断题

**常见问法**：“符合原文的是……”“下列说法不正确的是……”。

**核心考点**：逐项定位原文，并核对下列要素。

| 核对维度 | 常见变化 |
| --- | --- |
| 主体 | 把甲的行为或观点换成乙的 |
| 范围 | 将“部分”扩大为“全部” |
| 数量 | 混淆“增加了”和“增加到” |
| 时态 | 将“将要”改为“已经” |
| 可能性 | 将“可能”改为“必然” |
| 条件 | 遗漏限定条件，混淆必要条件和充分条件 |
| 因果 | 强加因果、颠倒因果，或把相关当因果 |
| 比较 | 更换比较对象或比较标准 |

**常见错误**：凭常识作答；漏看否定问法；认为“表述绝对”就一定错。

### 4. 标题选择题

**常见问法**：“最适合作为这段文字标题的是……”。

**核心考点**：

- 准确覆盖核心话题与主要观点。
- 范围适当，避免过宽、过窄。
- 表达简洁，并与文体、语气相符。
- 在内容准确的基础上比较概括性和吸引力。

**常见错误**：只看标题是否生动；选择只对应某个例子的标题。

### 5. 态度观点题

**常见问法**：“作者对……的态度是……”“作者认为……”。

**核心考点**：

- 区分作者观点和文中转述的他人观点。
- 注意评价词、语气词、转折和结论。
- 判断支持、反对、质疑、保留或客观介绍等态度。
- 把握态度程度，不能将审慎表述理解为完全否定。

**常见错误**：把引用观点当作者观点；把没有明确表态理解为支持或反对。

### 6. 词句理解题

**常见问法**：“文中某词的含义是……”“画线句指的是……”。

**核心考点**：

- 根据上下文确定指代对象。
- 结合解释、举例、转折等内容理解具体含义。
- 理解比喻或抽象表达在文中的实际所指。
- 将选项代回原文，检查语义与逻辑是否一致。

**常见错误**：只看词典义；脱离上下文解释；遗漏指代对象的限定信息。

## 四、语句表达

### 1. 语句排序题

**核心考点**：

- **首句判断**：是否适合引出话题，有没有依赖前文的信息。
- **指代衔接**：“这”“其”“上述”等指向什么内容。
- **关联词衔接**：关联词是否配套，逻辑是否连贯。
- **话题衔接**：相邻句是否围绕同一对象展开。
- **顺序关系**：时间、空间、事理、提出问题到解决问题等。
- **整体结构**：排序后是否形成完整、自然的语段。

**建议步骤**：结合选项比较首句 → 找确定的相邻句 → 排除不符选项 → 通读验证。

**常见错误**：仅凭某个词就绝对排除首句；局部衔接成立，但整体逻辑不通。

### 2. 语句填空题

**核心考点**：横线位置、前后话题、逻辑关系和表达风格。

| 横线位置 | 优先检查 |
| --- | --- |
| 开头 | 是否能引出后文，是否具有统领或铺垫作用 |
| 中间 | 能否承接前文并引出后文，形成完整逻辑 |
| 结尾 | 是否总结前文、形成结论或自然延伸 |

位置只是线索，不能据此机械判断句子作用。

**常见错误**：只看前文、不看后文；内容相关但无法衔接；凭空引入新话题。

### 3. 下文推断题（接语选择题）

**常见问法**：“作者接下来最可能讲述的是……”。

**核心考点**：

- 在理解全文的基础上，重点观察尾句。
- 识别新引入、尚未展开的话题或问题。
- 判断下文可能继续解释、举例、分析原因还是说明措施。
- 排除前文已经充分展开、突然转换话题或推断过远的内容。

**常见错误**：选择只是重复前文的内容；只看尾句关键词，不考虑全文方向。

## 五、复习时要避免的机械口诀

- “转折之后是重点”：应结合整个语段，确认转折内容的作用。
- “看到问题就选对策”：对策必须有文段依据，并符合提问要求。
- “绝对表述一定错”：应核对原文是否支持该表述。
- “意图题一定选言外之意”：不能为追求推断而脱离文段。
- “有指代词一定不能作首句”：应判断是否依赖前文，以及指代是否在句内已经明确。

## 六、适合周末学习的使用方法

当前情况：行测约60分，主要利用周末备考。

1. 先做限时混合题，统计各细分题型的正确率与用时。
2. 每两周集中处理一个反复出错的细分问题。
3. 做错后先独立重做，再查本框架和解析。
4. 记录具体原因，不只写“粗心”或“没读懂”。
5. 下个周末独立重做旧题，再用陌生题验证是否改善。

### 错题记录模板

| 日期／题目来源 | 细分题型 | 对应考点 | 具体错误原因 | 下次采取的动作 | 隔周重做结果 |
| --- | --- | --- | --- | --- | --- |
| 示例 | 主旨概括 | 观点与例子的关系 | 把举例内容当成全文主旨 | 先判断例子在证明什么，再核对选项覆盖范围 | 待重做 |
| 示例 | 细节判断 | 可能性 | 漏看“可能”，选择了“一定” | 核对原文和选项的限定词 | 待重做 |
| 示例 | 逻辑填空 | 搭配对象 | 两词含义相近，但适用对象不同 | 同时检查词义和搭配对象 | 待重做 |

### 建议统计的分类

- 逻辑填空：语境分析、词义辨析、搭配判断、整体验证。
- 片段阅读：主旨、意图、细节、标题、态度、词句理解。
- 语句表达：排序、填空、下文推断。

先通过错题分布确定训练重点，再调整学习时间；不必平均用力，也不必从头背完整份框架。
